# Yo haku（ハッカソン）

### 概要

友達をご飯や遊びに気軽に誘えるアプリ

### 課題

普段の友達や、地元の疎遠になった友達をもっと気軽に誘いたい！

### 技術

- React: インターンで学んだアーキテクチャを実践
- Go: 初めてのバックエンド、設計を試行錯誤しながら実装。
- AWS: 初めてのインフラ。フロント/バックエンドのCICDを実装。

# Rehabit（ハッカソン）

### プロダクト

リバビリ箇所の可動域を計測して効果を可視化するアプリ

リハビリは効果を実感しづらく、継続のモチベーションが下がりやすい。

### 工夫

- UXを重視した設計
  - 「自分でも毎日使いたいと思えるか」を意識
  - 継続しやすい体験を重視
